# opencode-keymap-cheatsheet

TUI-плагин для OpenCode 2.2.0: показывает список доступных клавиатурных
сокращений по `Ctrl+Alt+K`.

## Зачем

В OpenCode 2.2.0 `which-key` объявлен в keybind-схеме и документации, но
обработчика и панели нет: `which-key.toggle` встречается только в
`packages/tui/src/config/keybind.ts` и docs, а в TUI-плагинах отсутствует.
`Ctrl+P` открывает палитру команд, `F1` — короткий Help, но не список биндов.

Плагин закрывает именно эту нишу: читает текущие команды из keymap и показывает
их сгруппированный список с фактическими сочетаниями клавиш.

## Возможности

- `Ctrl+Alt+K` открывает и закрывает диалог со списком сокращений.
- Команды сгруппированы по `group`, внутри группы отсортированы по названию.
- Показываются реальные бинды из keymap, включая multi-key sequences
  (`ctrl+x p`, `<leader>v`) и альтернативные сочетания через ` / `.
- Поиск: печатайте в поле ввода — фильтрация по названию команды, группе и
  клавишам. Точная фраза имеет приоритет (например, `ctrl+x p`), иначе
  несколько слов должны встретиться все (например, `session tab`).
- Прокрутка: `↑`/`↓`, `PgUp`/`PgDn`, `Home`/`End`; работает и колесо мыши.
- Последовательности, которые используют несколько команд, помечаются `dup`.
- `Esc` закрывает диалог; повторное открытие начинает с чистого фильтра.

## Установка

```bash
git clone <repo> ~/github/opencode-keymap-cheatsheet
ln -s ~/github/opencode-keymap-cheatsheet \
      ~/.config/opencode/plugins/keymap-cheatsheet
```

Перезапустить OpenCode или выполнить `/reload`. В логе должно появиться:

```text
loading plugin id=.../plugins/keymap-cheatsheet entrypoint=.../tui.tsx
```

Проверка: `Ctrl+Alt+K` в TUI.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Ctrl+Alt+K` | открыть / закрыть список |
| ввод текста | фильтр по команде, группе или клавишам |
| `↑` / `↓` | прокрутка на строку |
| `PgUp` / `PgDn` | прокрутка на страницу |
| `Home` / `End` | в начало / в конец |
| `Esc` | закрыть |

## Разработка

```bash
npm install
npm run check   # TypeScript, без emit
npm test        # unit-тесты чистой логики (node:test)
npm run verify  # check + test
```

Чистая логика (нормализация shortcuts, сборка строк, группировка, фильтрация)
вынесена в [`lib.ts`](lib.ts) и покрыта тестами в
[`tests/lib.test.ts`](tests/lib.test.ts).

Для локальной проверки удобно держать симлинк из `~/.config/opencode/plugins`
на этот каталог.

Живой тест в tmux:

```bash
tmux -L test new-session -d -s whk -x 140 -y 45 "opencode --standalone"
sleep 22
tmux -L test send-keys -t whk C-M-k
sleep 2
tmux -L test capture-pane -p -t whk -S -45
tmux -L test kill-server
```

## Ограничения

- Показываются именованные команды, доступные в keymap на момент открытия.
  Анонимные inline-биндинги без заголовка (внутреннее редактирование ввода) в
  список не попадают.
- `bind: false` не скрывает команду: это лишь отключение fallback-бинда слоя;
  фактические бинды из конфига всё равно показываются.
- Список — снимок на момент открытия; изменения keymap при открытом диалоге не
  перерисовываются до повторного открытия.
- `dup` означает, что последовательность встречается у другой команды.
  Повторы внутри одной команды схлопываются.
- Плагин только читает keymap, не выполняет команды и не заменяет `which-key`
  из upstream.
- Нужен OpenCode 2.2.0+ и `@opencode/plugin` 2.2.0 (OpenTUI 0.7).
